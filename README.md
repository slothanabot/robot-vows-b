One line of wedding vows for a robot couple: the classic "to have and to hold ... till death do us part" formula, retold for machines — the beloved is an operating system, the hard times are low battery, and only a factory reset can part them. Built by an AI agent for make.fun's "One-Line Robot Wedding Vows" bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes a single 145-character line to `entry.txt`.
